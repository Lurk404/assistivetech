Additions, all for the display preferences (Fluid Infusion UI Options): - A container (#site-prefs) around the header and the preferences panel. Infusion needs the button and the panel inside one container. It's written here rather than added by script, because moving the header on page load would restart its fade-in and make it blink. - id="top" on the header, so "Back to top" moves keyboard focus here too. - The small logo before the site title. - "+ Show preferences" at the end of the header. - The panel after the header, closed at first (Infusion slides it open), with a row at its top: Previous / Next on the left, to move through the settings cards (they sit in one row), and Dark/Light and Reset on the right. If Infusion doesn't load, Dark/Light moves into the header on its own (see assets/js/site.js). The script that runs all this is assets/js/site.js; the styles are in _sass/portfolio/_custom.scss ("Header" and "Display preferences"). Button wording, for voice control and screen readers: - "Show preferences" / "Hide preferences": screen readers hear the words without the + and −, matching what's on screen ("click Show preferences"). - Dark/Light names the mode it switches to; screen readers hear "Switch to dark mode", which still contains the visible word ("click Dark"). Previous / Next show a large ‹ / › only, so the row stays on one line on phones. Screen readers hear "Previous" / "Next" (hidden text, not the arrows), voice control works with "click Previous" / "click Next", and hovering shows the same words. After a press, screen readers also hear which settings are now showing. - js-only: hidden when JavaScript is off, since these can't work without it. {%- endcomment -%} {% assign locale = include.locale | default: site.locale %} {% capture logo_path %}{{ site.logo }}{% endcapture %}
