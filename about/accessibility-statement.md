# Accessibility Statement

## Accessibility Features of this Resource

This resource is designed to meet [Web Content Accessibility Guidelines 2.1](https://www.w3.org/TR/WCAG21), level AA. To create an accessible resource, authors incorporated the following:

- Minimum 14 pixel body text.
- Pages are built with a consistent heading structure.
- All content has appropriate colour contrast.
- Information is not conveyed by colour alone.
- Content can be zoomed to 200% with no need for horizontal scrolling.
- All videos with audio created by the authors are accurately captioned.
- All images include alternative text or are marked decorative.
- Tables are properly formatted.
- All link text is descriptive.
- Links do not open in a new window or tab, except where indicated.

Use the  <img class="inline" src="../assets/images/using-this-resource/button-show-preferences.svg" alt="" width="170" height="44"> **+ Show preferences** button at the top of this page to customize the appearance of this resource. For more information, review [Using This Resource](../about/using-this-resource.md).

## Contact Information

If you encounter an accessibility barrier or have any other questions or comments, contact [assistivetech@langara.ca](mailto:assistivetech@langara.ca).

Please include as much of the following information as possible:

- Location of the issue, including the web address and/or page title.
- A description of the issue.
- The computer or device, software, browser, and other technology you are using.
  - e.g., iOS, Safari, VoiceOver

A thorough description will assist us in addressing any issues and improving the accessibility and usability of this resource.
