# Mind Mapping

<img src="../assets/images/mind-mapping/mind-mapping-icon.png" alt="" width="140"> <!-- review-alt -->

A mind map is a diagram used to visually organize information in a hierarchy of topics with links between concepts. Mind mapping can help with brainstorming ideas for a paper, organizing notes and research, outlining tasks, and making connections between concepts. Mind maps can be particularly useful to help with organization, focus, and reducing distractions. Mind mapping tools are especially helpful when they can convert mind map diagrams to text-based outlines. An outline is a great way to start an essay or assignment.

<details id="gitmind" markdown="block">
<summary>GitMind</summary>

<img src="../assets/images/logos/gitmind.jpg" alt="" width="300"> <!-- review-alt -->

[GitMind](https://gitmind.com) is a free mind mapping tool that can be used online or downloaded for Windows, macOS, iOS, and Android. Users can create an account for free and use many useful features. However, some features of GitMind require a paid account.

1. Create a new map.
   ![The GitMind home page with New map circled.](../assets/images/mind-mapping/gitmind-new-map.png) <!-- review-alt -->
2. Use the toolbar to add nodes, subnodes, and customize the appearance of content.
   ![The GitMind toolbar with buttons for undo, redo, adding nodes and subnodes, formatting, inserting content, and more.](../assets/images/mind-mapping/gitmind-toolbar.png) <!-- review-alt -->
3. Select a node and click **Insert** to add images, notes, links, and more.
   ![The Insert button circled on the GitMind toolbar, with a menu offering Image, Note, Comment, Hyperlink, Equation and Sticker.](../assets/images/mind-mapping/gitmind-insert-menu.png) <!-- review-alt -->
4. Select **Style** to change background, theme, and map style.
   ![The Style button with its tooltip, Show or hide style and format options.](../assets/images/mind-mapping/gitmind-style-button.png) <!-- review-alt -->
5. Select **Outline View** to see a hierarchical text version of your map.
   ![The view menu at the bottom of the map with Mind Map, Outline View and Outline+Mind Map.](../assets/images/mind-mapping/gitmind-outline-view.png) <!-- review-alt -->
6. **Export** as an image or document.
   ![The Export button with its tooltip, Export to other formats.](../assets/images/mind-mapping/gitmind-export.png) <!-- review-alt -->
   Note, when exported to a Word document, nodes and subnodes appear as different size text but are not coded as hierarchical heading levels.

GitMind offers many useful features. One that may be particularly useful is **Split Screen**.

1. Open the **More** menu and select **Split Screen**.
   ![The More menu with Split screen circled. Other options include Focus, Find & Replace, Version history, Hotkeys and Setting.](../assets/images/mind-mapping/gitmind-split-screen.png) <!-- review-alt -->
2. Open a document, webpage, or whiteboard to use GitMind for project planning, note taking, and research.

To review keyboard shortcuts, select **More** and click **Hotkeys**.

Learn more in [How to use GitMind](https://gitmind.com/faq/how-to-use-gitmind.html).

<details id="mindmeister" markdown="block">
<summary>MindMeister</summary>

![](../assets/images/logos/mindmeister.png) <!-- review-alt -->

[MindMeister](https://www.mindmeister.com) is an online mind mapping tool. MindMeister is free to use but a paid version has more features. MindMeister is cloud based and can be accessed via web browser. Users need to create an account to use MindMeister.

To create a mind map:

1. Select **Mind Map**.
2. Begin with a title or main topic.
   1. Press <kbd>Tab</kbd> to add a subtopic.
   2. Press <kbd>Enter</kbd> to add a sibling (equivalent subtopic).
3. Select **Actions** to add comments, notes, connections, and other tools.
   ![The MindMeister Add panel with Connection, Comment, Note, Media, Attachment and Task.](../assets/images/mind-mapping/mindmeister-actions.png) <!-- review-alt -->

To switch to a text outline:

1. Click **Mind Map** in the bottom left corner of the window.
   ![The Mind Map menu open with Mind Map and Outline options.](../assets/images/mind-mapping/mindmeister-outline.png) <!-- review-alt -->
2. Select **Outline**.
3. Changes, edits, and additions in Outline view will be reflected in Mind Map.

To export an outline:

1. Select **Export** in the top left.
   ![The map title menu open with Export and Print.](../assets/images/mind-mapping/mindmeister-export.png) <!-- review-alt -->
2. Choose **Export…**
3. Choose **Document Outline**.
   1. Check **Include topic styling**.
4. Click **Export…**
   1. The exported document will be in .RTF format with a hierarchical heading structure.

Learn more about additional [MindMeister features](https://www.mindmeister.com/pages/features).

</details>

<details id="mindmup" markdown="block">
<summary>MindMup</summary>

![](../assets/images/logos/mindmup.png) <!-- review-alt -->

MindMup is an online mind mapping tool. MindMup is free to use but a paid version has more features. Users need a Google account to use MindMup.

To get started:

1. Navigate to [MindMup](https://app.mindmup.com).
2. Select **CREATE A FREE MAP**.
3. On the first visit, users will be prompted to sync MindMup with their Google account.

[To create a mind map](https://www.mindmup.com/tutorials/concept_mapping.html):

1. Build the mind map by entering topics, subtopics, and siblings.
   1. Press <kbd>Tab</kbd> to create a subtopic.
   2. Press <kbd>Enter</kbd> to create a sibling topic.
   3. The toolbar has buttons to create siblings, subtopics, and connections.
2. [Create connections between nodes](https://www.mindmup.com/tutorials/connections.html) by selecting the first node and then clicking **Connect to another node** on the toolbar and clicking the destination node, or holding <kbd>Alt</kbd> and clicking the destination node.
3. Press <kbd>N</kbd> to [add a note to a topic](https://www.mindmup.com/tutorials/notes.html).
   1. Or, open **View > Sidebar > Show Notes**.
   2. The sidebar opens to add and edit notes.

To export an outline:

1. Open the **File** menu.
2. Select **Download as**.
3. Choose **Outline**.
4. Ensure **MS Word/Google Writer** is the selected format.
5. Check the **Include text notes** box.
   1. This is necessary to export a text outline.
6. Click **Export**.
7. Click **Download**.
8. MindMup will export as a Word document.

The exported outline uses lists to reflect the hierarchy of the mind map. However, users can set the number of heading levels desired by changing the settings in the **Outline type** menu before exporting.

- [MindMup Tutorials and Guides](https://www.mindmup.com/tutorials/index.html)
- [How to create document outlines with MindMup 2.0 (video, 1:08)](https://www.youtube.com/watch?v=hfmfblIqXD0)

<details id="mindomo" markdown="block">
<summary>Mindomo</summary>

![](../assets/images/logos/mindomo.png) <!-- review-alt -->

[Mindomo](https://www.mindomo.com/login) is an online mind mapping tool. Mindomo is free to use but a paid version has additional features. Mindomo is cloud based and can be accessed via web browser.

How to create a [mind map](https://help.mindomo.com/mind-mapping/what-is-mind-mapping):

1. Click **Create** and choose a diagram style.
   1. We recommend **Blank mind map** or **Blank concept map**.
2. Click on the placeholder and type the main topic.
3. Press <kbd>Tab</kbd> to create a subtopic.
   1. Repeat as necessary.
4. Press <kbd>Enter</kbd> to create a sibling topic.
5. Click on the down arrow for additional options.
   1. **Notes** can be used to add detail.
   2. Hyperlinks and attachments.
   3. Media such as images, videos, audio recordings, and icons.
   4. Create relationships between topics with a line.

Open the menu and select **Shortcuts** to see a list of keyboard shortcuts to add topics, subtopics, and relationships between topics.

To convert a mind map to an outline:

1. Expand the menu and select **View as Outline** to see a bullet point version of the mind map.
   <img src="../assets/images/mind-mapping/mindomo-view-as-outline.png" alt="The Mindomo menu open with View as Outline highlighted." width="400"> <!-- review-alt -->
2. Changes, edits, and additions in Outline view will be reflected in Mind Map.

To export an outline:

1. Open the menu and select **Export**.
2. Choose **Text File (.txt)**, click **Export** and select **My Computer**.
3. The exported document includes tab indents to show structure.

- [Getting started with Mindomo](https://help.mindomo.com)
- [Mindomo how to video playlist](https://www.youtube.com/watch?v=oXKnrDLg2KA&list=PLOwUlX-xhRljs_vpUeWPUvh2o0yfoHzg-)

</details>

<details id="word-outline" markdown="block">
<summary>Word Outline</summary>

<img src="../assets/images/logos/word.png" alt="" width="150"> <!-- review-alt -->

Word cannot create a visual mind map but includes useful tools to organize information in an outline. Word Outline view is only available on desktop versions (Windows, macOS) of Word. To install Word, navigate to [Microsoft 365](https://www.office.com/?auth=2), sign in, and select **Install apps**.

To create an outline:

1. Navigate to **View > Outline**.
   ![The Word View tab with View and Outline circled and the Outline View tooltip showing.](../assets/images/mind-mapping/word-outline-button.png) <!-- review-alt -->
2. Enter your main topic as **Level 1**.
3. Press <kbd>Tab</kbd> and enter subtopics. Repeat to create as many levels as needed.
   1. Or use the promote and demote buttons to set the level.
4. Enter links, notes, and evidence as body text.
   ![Outline view with the level menu set to Body Text circled, and an outline of a main topic, two subtopics, evidence headings, and notes in body text.](../assets/images/mind-mapping/word-outline-body-text.png) <!-- review-alt -->
5. Click **Close Outline View** to return to the document. The outline will appear as text with heading levels organizing topics, subtopics, and content.
   ![The outline in the document as headings for the main topic, subtopics and evidence, with notes as body text.](../assets/images/mind-mapping/word-outline-result.png) <!-- review-alt -->

Learn more about [creating an outline in Word](https://support.microsoft.com/en-us/office/import-a-word-outline-into-powerpoint-a25f6e01-9a19-4c0d-a108-7f533e42dfe9).

</details>

<details id="inspiration" markdown="block">
<summary>Inspiration</summary>

<img src="../assets/images/logos/inspiration.jpg" alt="" width="200"> <!-- review-alt -->

Inspiration allows users to create diagrams, outlines, and maps. Inspiration includes templates and a built-in tutorial. [Inspiration can be downloaded](https://www.inspiration-at.com/inspiration-10) as a 30-day free trial or is available for $144 CAD.

To begin:

1. Begin by choosing a document type: Diagram, Outline, or Map.
   ![The Inspiration Starter window with Diagram, Outline, Map, Open, Templates and Learn to Use buttons.](../assets/images/mind-mapping/inspiration-starter.png) <!-- review-alt -->
   1. A diagram allows for creative arrangement of topics, subtopics, and notes.
      1. [Learn more about the diagram toolbar](https://v10.inspiration-manual.com/219.html).
      2. [Overview of how the diagram tool works](https://v10.inspiration-manual.com/3256.html).
   2. Maps follow a more structured process with a central main idea.
      1. [Learn more about the map view toolbar](https://v10.inspiration-manual.com/2437.html).
      2. [Overview of how maps work](https://v10.inspiration-manual.com/3314.html).
   3. Outline is a text based hierarchical list used to arrange ideas.
      1. [Learn more about the outline toolbar](https://v10.inspiration-manual.com/510.html).
      2. [Overview of the outline tool](https://v10.inspiration-manual.com/3257.html).
2. Start with your main topic and add subtopics.
   1. Use the **Relate** tool in a Map to create connections.
      1. Learn more about the [Relate tool](https://v10.inspiration-manual.com/2474.html).
      2. [Adding notes to a map](https://v10.inspiration-manual.com/2476.html).
   2. Use the **Link** tool in a Diagram to create connections.
      1. Learn about [creating links in a diagram](https://v10.inspiration-manual.com/262.html).
      2. [Work with notes in a diagram](https://v10.inspiration-manual.com/427.html).
3. In either mind map style, select **Outline** to view a text-based outline.
   1. Or, open the **View** menu and choose **Outline**.
4. Once your Outline is complete, select **File > Export**.
5. Choose **Microsoft Word**.
6. Users can change options for what to include in the export, but default settings are advised.
7. Click **Save** and then open the document in Word to use the outline to complete your project.

For more information:

- [Inspiration resources and videos](https://www.inspiration-at.com/resources)
- [Inspiration explainer videos](https://www.inspiration-at.com/inspiration-explainer-videos/#explainer-videos)
- [Inspiration how-to videos](https://www.inspiration-at.com/inspiration-for-windows-how-to-videos)

<details id="kurzweil" markdown="block">
<summary>Kurzweil</summary>

![](../assets/images/logos/kurzweil-3000.png) <!-- review-alt -->

Kurzweil is a full literacy suite with many tools. One of those tools is Brainstorm. Brainstorm is a mind map that can be converted to an outline and used to create a draft document.

Kurzweil is available via [ATBC grant funding](http://www.at-bc.ca/programs/grant-equipment-for-students-csg), or by [purchasing a Kurzweil license](https://www.bridges-canada.com/products/kurzweil-3000-english-standalone) ($1065).

Visit the [Kurzweil download centre](https://www.kurzweiledu.com/products/download-center.html) for options.

By default Kurzweil will read aloud as users type. To deactivate or change this, navigate to **Tools > Options** and check or uncheck appropriate features under **Speak as Typing**.

Select **File > New > Brainstorm > Blank** or **From Template**. Templates include many different pre-built layouts.

<img src="../assets/images/mind-mapping/kurzweil-start-screen.png" alt="The Kurzweil 3000 start screen with Read (Open Existing File), Write (New Draft, New Brainstorm, New Outline) and Scan (Scan Document) options." width="600"> <!-- review-alt -->

1. Enter a main topic.
2. Add subtopics by adding an oval, rectangle, or rounded rectangle.
   1. The use of shapes and colours may be a useful way to organize ideas in addition to the visual structure of the brainstorm.
3. The Brainstorm Palette holds tools for shapes, link tool, and other options.
   ![The Brainstorm Palette with buttons for Quick Takes, links, arrange, shapes, colours and delete.](../assets/images/mind-mapping/kurzweil-brainstorm-palette.png) <!-- review-alt -->
   1. Use **Quick Takes** to quickly enter subtopics.
   2. Create **Links** between ideas.
   3. Select **Arrange** to clean up the diagram.
      1. This may significantly change the appearance of your diagram. You can revert to the prior view by selecting **Edit > Undo**.

To convert the diagram to an outline:

1. Select **Outline View**.
   ![The Kurzweil Write toolbar with the pointer on the Outline View button.](../assets/images/mind-mapping/kurzweil-outline-view.png) <!-- review-alt -->
2. **Outline View** converts the diagram to a list of indented bullet points.
   1. Users can add information, notes, links, or other media to the **Outline View**.
   2. Select **Split Screen View** to open a blank **Draft** document beside the outline. Use this to begin crafting a document.
3. Choose **Save As…** and select **MS Word 2007 (\*.DOCX)**.
4. Open the document in Word to complete the project.

[Kurzweil Getting Started Guide](https://www.kurzweiledu.com/files/pdf/2018shared/win_getting_started_guide.pdf)

</details>
