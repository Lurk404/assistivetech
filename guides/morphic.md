# Morphic

<img src="../assets/images/logos/morphic-logo.jpg" alt="" width="96"> <!-- review-alt -->

Morphic is a basic toolbar that helps with quick access to built-in accessibility tools. Morphic is free and available for Windows and macOS.

[Download Morphic](https://morphic.org/download)

## Start Morphic automatically

1. Select the Morphic icon on the toolbar.
   ![The MorphicBar with a red arrow pointing to the Morphic icon at its right end.](../assets/images/morphic/morphic-icon-on-toolbar.png) <!-- review-alt -->
2. Click **Automatically start Morphic** and **Show Morphic Bar at start**.
   ![The Morphic menu with red arrows pointing to Automatically start Morphic and Show Morphic Bar at start.](../assets/images/morphic/start-options-menu.png) <!-- review-alt -->

## Toolbar shortcuts

The Morphic toolbar provides shortcuts to built-in accessibility tools.

![The MorphicBar, with buttons for Text Size (plus and minus), Magnifier (Show and Hide), Snip (Copy), Read Selected (Play and Stop), and Contrast & color (Contrast, Color, Dark and Night).](../assets/images/morphic/morphicbar.jpg) <!-- review-alt -->

1. **Text Size**
   1. Use the **+** and **–** icons to change the size of text.
2. **Magnifier**
   1. Click **Show** or **Hide**.
   2. Activating Magnifier will use default settings.
      1. These settings can be changed under **Settings > Ease of Access > Magnifier**.
   3. Once Magnifier is on, the magnifier window appears, allowing users to change view, zoom level, and other settings.
3. **Snip** takes a screenshot and automatically copies it, allowing users to paste the screenshot in a document quickly.
   1. Select **Snip**, then click and drag to take a screenshot of the selected area.
4. **Read Selected**
   1. Highlight text and click the play button under Read Selected to hear the text read aloud.
   2. Change voice settings in **Settings > Time & Language > Speech**.
5. **Contrast & color** allows users to adjust contrast, color filters, and activate dark and night mode.

## Windows Ease of Access shortcuts

Morphic includes shortcuts to Windows Ease of Access settings.

1. Select the Morphic icon on the toolbar.
2. Choose **More settings to make the computer easier**.
   ![The Morphic menu with More settings to make the computer easier selected. A submenu lists Windows settings for MorphicBar controls (Magnifier, Read Aloud, Color Vision, Night Mode, Dark Mode and Contrast), other key Windows settings (Mouse, Pointer Size, Keyboard, Language and All Accessibility Options), and Stop Key-repeat.](../assets/images/morphic/more-settings-submenu.png) <!-- review-alt -->
3. The submenu has shortcuts to all available Windows accessibility tools and settings.
